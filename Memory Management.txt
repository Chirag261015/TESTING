Memory Scope & Isolation	Define what a user, a project and the organisation can see, with tests that one tenant cannot read another tenant's memory.
Cache - Production Settings	Set CACHE_ALLOW_MEMORY_FALLBACK=false in staging and production, add a Redis health check, memory limit and allkeys-lru eviction.
Cache - Keys, TTL & Invalidation	Key format tenant:project:type:version, a TTL for each cached item (embeddings, retrieval results, tool results, previews), and cache clearing when ingestion changes a document.
LLM Prompt Caching	Cache large stable blocks (Leading Practice context, tool definitions, project profile), not only the system prompt; show the hit rate and savings in OpenObserve.
Run State & File Storage	Checkpoints on Postgres with retention for finished runs, workspace files and uploads on S3 with per-tenant folders, sessions and queue state only in Redis.
Memory Observability	Log which memories were used in each answer, so a person can see why the agent remembered something and correct it.
